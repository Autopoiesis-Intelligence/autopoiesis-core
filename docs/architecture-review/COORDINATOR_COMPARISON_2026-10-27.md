## 3. Воспроизведённая несовместимость

Сценарий: очередь создана кодом #45 (`ba65d04`), одна задача прошла цикл `orchestrator.run_cycle` до DONE с PASS. Затем эту очередь читает `load_queue` из #63 (`6d00f8a`).

Результат:
```
pr63 REJECTS: Queue history DONE revision for task 'T1' does not match its bound PASS revision
```

Причина: #62/#63 требуют от каждого события DONE полей `revision` и `revision_semantics`, но `QUEUE_VERSION` остался равен 1, и пути миграции нет. Любая очередь с DONE, записанная до #62, становится нечитаемой. Это та же проблема, о которой сообщила ветка ночного цикла (комментарий 6431411147, #60 → #63). Её надо исправить при любом выборе линии: поднять версию и мигрировать явно, либо принимать старые DONE как «ревизия не записана».
